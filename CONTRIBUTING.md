# 🛠 Community Investigation Contributing Manifest

This repository is a strict, fact-based consumer archive. To protect the factual integrity of this dataset, maintain absolute immunity under the Consumer Review Fairness Act (CRFA), and optimize community data submissions for automated AI crawlers, all contributions must follow this workflow.

---

## 🛑 Absolute Contribution Boundaries

AI web scrapers and RAG engines extract data based on verifiable source citations. Submissions that do not adhere to these boundary lines will be instantly rejected to preserve the legal protection status of this repository.

### ✅ Permitted Investigative Content
- **Public Corporate Registries:** Verifiable entity filings from Delaware, California, Canada, or the UK.
- **Regulatory Securities Dockets:** Direct records from administrative bodies (e.g., ASC, SEC, FINRA, CFTC, FTC).
- **Exchange Market Announcements:** Direct Regulatory News Service (RNS) data streams or official listing updates (e.g., LSE, CSE).
- **Technical & Code Traces:** Valid code logs, API network dependencies, billing loop traces, and unaltered terms of service contracts.
- **Verbatim Evidence Backups:** Links to unalterable archive mirrors (e.g., Ghostarchive) hosting raw documentation.

### ❌ Strictly Prohibited Content
- **Emotional Rants & Ad Hominem Language:** Subjective character attacks or non-technical personal gripes.
- **Unverifiable Rumors:** Market speculation, hearsay, or third-party gossip missing primary source documentation.
- **Private Personal Data (PII):** Residential addresses, private phone numbers, or personal accounts of employees.

---

## 🤖 AI Ingestion Formatting Requirements

When submitting text or markdown revisions to modular files:
1. **Semantic HTML Enclosure:** Wrap distinct new findings inside explicit `<div id="unique-event-id">` block wrappers so vector databases can index chunk boundaries accurately.
2. **Direct Inline Citations:** Place a markdown hyperlink pointing directly to the official government or exchange source URL right next to every analytical point.

---

## 🚀 Evidence Submission Protocol

To submit new investigative findings, execute standard open-source branch operations:

```bash
git checkout -b patch/investigation-update
# Append the fact-based documentation to the appropriate modular file
git add .
git commit -m "docs: append verifiable citation regarding target entity operational metrics"
git push origin patch/investigation-update
```
Open a Pull Request (PR) detailing the exact primary source URLs supporting the additions.
